Design Discipline

Clarity is a competitive advantage.

Markets produce more information than most interfaces can communicate effectively. Eudaimonia is designed around a different principle: show the information that matters, keep the interface out of the way, and let the user remain in control.

Modern financial applications too often prioritize decorative visuals over functional speed. Layers of nested cards, non-standard rounding, and slow web wrappers conceal the fundamental price mechanics professional market participants need.

Eudaimonia is built strictly as a high-density, keyboard-first terminal. Every pixel serves data comprehension: clean tabular monospace alignment, instantaneous timeframe switching, deterministic option valuation, and transparent feed status.

Density Without Visual Noise

Strict monospace alignment and purposeful contrast maximize readable information per screen without fatigue.

Deterministic Local Computation

Black-Scholes Greeks, Put-Call Ratios, and Max Pain calculations execute locally in Python/SciPy with zero cloud telemetry.

Direct Keyboard Navigation

Eliminates mouse latency. Navigate options expiries, strike windows, and chart intervals with direct single-key shortcuts.

Data Integrity

Know what you’re looking at.

Market integrity begins with absolute clarity about your data source. Eudaimonia enforces strict architectural boundaries across four distinct data modes.

LIVE FEED

Broker WebSocket Feed

Direct, authenticated binary WebSocket connection to your registered broker API (Zerodha Kite Connect, Upstox v2). Sub-millisecond local tick normalization and Level-2 5-depth order books.

DELAYED

Delayed Snapshots

Exchange-delayed quotes suited for post-session study and non-critical analytical inspection. Permanently labeled with feed lag indicators in the terminal header.

HISTORICAL

Aggregated Bars

Daily and intraday historical OHLCV candle bars fetched from authenticated broker endpoints or cached locally in a local SQLite database for offline analysis.

SIMULATED

Offline Mock Engine

Deterministic price and volatility simulation engine designed for testing keybindings, layouts, and Black-Scholes Greeks calculations outside trading hours without requiring broker credentials.

Data Access Disclosure: Eudaimonia is personal analytical client software. It does not resell, publicly broadcast, or redistribute raw exchange market data. Real-time market data access requires a valid, registered account with supported Indian brokerage platforms (e.g., Zerodha Kite Connect or Upstox) and remains subject to the broker's terms, API entitlements, and applicable SEBI regulations.

Architecture

Direct workflow. Minimal setup.

Designed for software engineers and quantitative traders who demand clean control over their analytical environment.

STEP 01

Connect your data provider

Configure your preferred broker adapter in your local .env file (Zerodha Kite Connect or Upstox v2), or launch immediately with the zero-configuration offline mock simulator.

STEP 02

Select contracts and underlyings

Specify your target index benchmarks (NIFTY, BANKNIFTY, FINNIFTY) or active equity watchlists to stream real-time quotes, options strike ladders, and 5-depth order books.

STEP 03

Analyze via terminal interface

Inspect live strike-by-strike Black-Scholes Greeks, Put-Call Ratios, Max Pain levels, and intraday candlestick charts with zero mouse latency.

INSTALLATION & QUICKSTART 
# 1. Clone the repository
git clone https://github.com/shomay12/eudaimonia.git
cd eudaimonia

# 2. Create and activate a Python 3.11+ virtual environment
python3 -m venv .venv
source .venv/bin/activate

# 3. Install dependencies in editable mode
pip install -e .

# 4. Configure local environment file
cp .env.example .env

# 5. Launch terminal in offline mock simulation mode
eudaimonia --mode MOCK --underlying NIFTY

Command Line Flags

The eudaimonia executable accepts runtime arguments to configure data modes, exchanges, and default symbols without editing code.

FLAG OPTIONS DESCRIPTION
--provider, -p mock, kite, upstox, dhan Market data provider adapter (default: mock)
--mode, -m MOCK, LIVE, HISTORICAL, DELAYED Runtime data feed mode (default: MOCK)
--exchange, -e NSE, BSE Default primary exchange (default: NSE)
--underlying, -u NIFTY, BANKNIFTY, FINNIFTY Default active underlying (default: NIFTY)
--version, -v — Display application version and author metadata
